# Guia de Contribuição - GRAMAP

Obrigado por se interessar em contribuir para o GRAMAP! Este documento fornece diretrizes e instruções para contribuições.

## 📋 Código de Conduta

Certifique-se de ser respeitoso e profissional em todas as interações.

## 🚀 Como Contribuir

### 1. Fork o Repositório

```bash
git clone https://github.com/seu-usuario/gramap.git
cd gramap
```

### 2. Crie uma Branch

```bash
git checkout -b feature/sua-feature
```

### 3. Faça suas Alterações

```bash
git add .
git commit -m "Descrição clara da mudança"
```

### 4. Push para a Branch

```bash
git push origin feature/sua-feature
```

### 5. Abra um Pull Request

Descreva claramente suas mudanças e por que devem ser incluídas.

## 📝 Padrões de Código

- Use JavaScript ES6+
- Adicione comentários em código complexo
- Siga o estilo existente
- Teste suas mudanças

## 🐛 Relatando Bugs

Descreva o bug, como reproduzi-lo e qual era o comportamento esperado.

## ✨ Sugestões de Funcionalidades

Descreva a funcionalidade desejada e por que seria útil.
